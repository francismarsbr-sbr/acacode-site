# acacode-site

Sitio estático de **acacode** (HTML, CSS y JS): home, catálogo y landings de cursos.

## Navegar en local

Doble clic en `abrir-local.bat` → http://localhost:5500

O abre `index.html` en el navegador.

## Estructura

- `index.html` — inicio
- `cursos.html` — catálogo
- `acerca-de-nosotros.html`
- `css/styles.css`
- `js/courses-data.js` — lista de cursos
- `js/main.js` — slider, contadores, filtros
- `cursos/` — landings de cada curso

## Cursos incluidos

- MiniGenios Scratch / STEM
- Marketing Digital
- Python / Python II
- IA Generativa
- Lógica de Programación I / II
- Alfabetización Tecnológica
- Hoja de Cálculo I / II
- Web Developer

## GitHub Pages

El sitio se publica automáticamente con Actions al hacer push a `main`.

URL típica: `https://<usuario>.github.io/acacode-site/`
