Propósito del curso

Datos que informan decisiones

Proporcionar las habilidades básicas en el manejo de las herramientas fundamentales de Microsoft Excel, permitiéndote transformar datos brutos en reportes organizados mediante tablas y gráficos que faciliten el análisis de datos y la toma de decisiones informadas.

La formación es un curso intensivo y 100% práctico diseñado para profesionales y estudiantes que necesitan un dominio rápido y eficiente de las funcionalidades esenciales de Excel. Siguiendo la metodología de Documento Único de Trabajo, cada módulo se aplica sobre un proyecto real — finalizarás con un documento funcional y una planificación docente completa asistida por IA lista para tu contexto laboral.

Metodología

Documento Único de Trabajo

El aprendizaje se construye progresivamente: cada módulo se aplica directamente sobre un proyecto real, garantizando un resultado funcional al terminar la formación.

01

Fundamentos de Excel

Interfaz, libros, hojas, celdas, ingreso de datos y formato básico de fuentes y celdas.

02

Gestión de Datos

Estructura, validación, corrección de errores y manejo de datos duplicados.

03

Fórmulas Esenciales

Operadores, referencias absolutas/relativas/mixtas y funciones matemáticas básicas.

04

Fórmulas Avanzadas

Funciones lógicas (SI), búsqueda (BUSCARV/H) y manipulación de textos.

Temario completo

5 módulos · De celdas a reportes

Un recorrido progresivo desde la interfaz de Excel hasta el análisis, presentación e integración de reportes automatizados.

01

Módulo 1

Fundamentos de Excel

Interfaz: entorno de trabajo, cinta de opciones y pestañas. Libros y hojas, gestión de hojas. Elementos: filas, columnas y celdas. Ingreso, edición y formato básico. Gestión de archivos, formato del libro, fuentes y celdas (tipo, tamaño, color, estilo, bordes).

Interfaz Celdas Formato
02

Módulo 2

Gestión de Datos

Estructura y formato de datos. Manejo de datos numéricos, corrección de errores comunes. Validación de datos con restricciones y operadores de comparación. Manejo de datos duplicados.

Validación Errores Duplicados
03

Módulo 3

Fórmulas y Funciones Esenciales

Operadores básicos y referencias. Suma, resta, multiplicación, división y porcentaje. Referencias absolutas, relativas y mixtas. Funciones: Promedio, Máximo, Mínimo, Contar y Contara.

Laboratorio: Cálculos con referencias mixtas

Fórmulas Referencias Promedio
04

Módulo 4

Fórmulas Avanzadas

Funciones lógicas: SI. Funciones de búsqueda y referencia: BUSCARV y BUSCARH. Funciones de textos: Izquierda, Derecha, NOMPROPIO, Espacios y Limpiar.

Laboratorio: Búsquedas y limpieza de datos

SI BUSCARV Textos
05

Módulo 5

Análisis y Presentación de Datos

Tablas y filtros: creación de tablas, filtros y ordenamiento. Gráficos de barras y circulares. Impresión y configuración de página. Integración y automatización de reportes.

Proyecto integrador: reporte analítico con tablas, gráficos e impresión profesional

Tablas Gráficos Reportes Impresión
